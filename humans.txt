	This file is called humans.txt, so it should be equally clear about
	the parts that were not made by hand.

	Artwork
	Images created with OpenAI's ChatGPT image generation tool. The designs
	were generated using AI based on prompts developed for the VIA Systems
	Lab, drawing inspiration from traditional Verona street plaques, Roman
	and medieval architectural elements, and the concepts of stable
	grounding, solid innovation, and lasting scientific knowledge. The final
	logo concepts were iteratively refined through successive prompts to
	simplify the design and adapt it for use as a stylized, monochrome logo
	and circular avatar.

	The emblem is declared in the page metadata with the IPTC digital source
	type "compositeWithTrainedAlgorithmicMedia": model output combined with
	human direction and editing.

	Code
	The markup, stylesheet, build tooling and documentation of this site
	were drafted with Claude Opus 5 (claude-opus-5) and reviewed by the
	authors, who remain responsible for what is published here. Commits
	written by an agent rather than by hand carry a [BOT] marker in their
	subject line, so the history distinguishes the two.
